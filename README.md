# Fraud Toaster

A privacy-first, open-source browser extension that detects and explains phishing attempts and social engineering attacks in real time.

Powered by a local-first analysis engine.

---

## 🍞 About the Project

Fraud Toaster is a cybersecurity awareness tool designed to help users **understand** online threats, not just block them.

Instead of silently filtering content, Fraud Toaster:
- Detects suspicious emails and web pages
- Explains why something is dangerous and how to defend against similar attacks in the future
- Runs entirely in the browser for privacy

---

## 📖 Core Philosophy

Most security tools hide threats.

Fraud Toaster explains them.

> “Security awareness through understanding, not just blocking.”
